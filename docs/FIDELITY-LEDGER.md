# FIDELITY-LEDGER.md — how far the generated report is from a real one

Generated by `npm run review:fidelity`. Do not hand-edit the tables — edit the checks in
`server/src/review/fidelity.ts` and re-run, so every line here stays something that was measured.

Two numbers, because they mean different things (critical 10 · major 4 · minor 1; lower is better):

- **Unattended 13** — the document that falls out with no human input.
- **Reviewer ceiling 7** — the same review with every candidate finding accepted.

The ceiling is the number that matters. §13.4 keeps judgement findings behind a human, so the
unattended document is *designed* to be thin — gaps that exist only there are a reviewer doing
their job, not a defect. Gaps that survive at the ceiling are what the platform genuinely cannot
produce, and those are the queue.

Zero at the ceiling would mean indistinguishable on everything this harness knows how to check,
which is not the same as indistinguishable. The human pass is what catches the rest.
